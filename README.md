# C2C Recruitment Automation System

An end-to-end recruitment automation project designed to streamline the USA Corp-to-Corp (C2C) recruitment workflow.

The system searches and filters C2C job opportunities, matches them with a candidate resume using NLP techniques, generates personalized recruiter outreach emails, tracks follow-ups, manages recruiter statuses, and provides a recruitment dashboard.

---

## 🚀 Project Overview

The C2C Recruitment Automation System automates multiple stages of the recruitment outreach process.
